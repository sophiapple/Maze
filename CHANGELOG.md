# Changelog

## 0.2.0

A standalone project layout separates the reusable Maze library from experiment configurations and recorded evidence.
This version includes scalar/vector energy implementations, differentiable planner training, scorer consensus, residual calibration, generalized MultiMaze allocation, feature encoding, frozen request collection, separate evaluation, and source-bound compact replay.
Seven selected development-cohort comparisons can be reconstructed from the bundled numeric records.
The repository also includes numerical and workflow tests, publication metadata, and a source-integrity audit.

The project version identifies this source package, not a new empirical result or a claim to regenerate unavailable historical model runs.
